Настройки SoundCloud Remote

По умолчанию мост слушает ws://127.0.0.1:8765/ws на том же ПК. Менять нужно, только если вы сменили порт моста.

Токен для расширения не нужен: соединение идёт через loopback (127.0.0.1) и принимается мостом без токена. Токен требуется только телефону — он зашит в QR-код подключения.
