# Chrome-расширение SoundCloud Remote

MV3-расширение: «глаза и руки» проекта. Читает состояние плеера SoundCloud
(название, исполнитель, обложка, позиция, лайк, repeat, shuffle, громкость
плеера) и выполняет команды, приходящие от ПК-моста через WebSocket
(`ws://127.0.0.1:8765/ws`, loopback, без токена — см. [`../PROTOCOL.md`](../PROTOCOL.md)).

## Установка (режим разработчика)

1. Откройте `chrome://extensions`.
2. Включите **«Для разработчиков»** (правый верхний угол).
3. **«Загрузить распакованное расширение»** → выберите папку `extension/`.
4. Откройте [soundcloud.com](https://soundcloud.com) — в консоли появится
   `[SC Remote] content script готов`.

Проверка без моста: клик по иконке расширения — попап покажет статус
«Мост: нет соединения» (нормально до Этапа 2) и состояние плеера
(название/исполнитель/позиция), если вкладка SoundCloud открыта.

## Как устроено

```
popup/          статус: мост, вкладка, текущий трек
options/        адрес моста (по умолчанию ws://127.0.0.1:8765/ws)
background/
  service_worker.js   WebSocket-клиент моста: hello/state/ack/error,
                      реконнект 1→30 c, ping 20 c + chrome.alarms (страховка
                      от засыпания SW), ретрансляция команд во вкладку
content/
  selectors.js  ЕДИНСТВЕННОЕ место с DOM-селекторами SoundCloud
  content.js    чтение состояния (DOM + медиа-элемент), команды:
                play/pause/toggle/next/prev/seek/volume/like/repeat/shuffle
```

Особенности:

- **Seek и громкость плеера** выполняются напрямую на медиа-элементе
  (`currentTime`, `volume`) — точнее и быстрее кликов по полосе.
- **Shuffle** часто лежит в панели очереди: расширение открывает её,
  кликает, возвращает как было (queue-assist), и кэширует последнее
  значение, пока панель закрыта.
- **Повтор** дотакливается до нужного режима (off/all/one), максимум 4 клика.
- Команды моста с `id` получают `ack`/`error`; без `id` — fire-and-forget,
  результат приходит обновлённым `state`.
- Если вкладка открыта до установки расширения, service worker переинжектит
  content script через `chrome.scripting`.

## Диагностика

- Попап: статус соединений и последняя ошибка.
- Расширение отвечает на внутреннюю команду `__debug_snapshot` — по ней видно,
  какие селекторы нашлись (пригодится при смене разметки SoundCloud).
- Селекторы чинятся в одном файле: `content/selectors.js` (кандидаты
  пробуются по порядку).
- «Расширение не подхватилось» на уже открытой вкладке: обновите вкладку
  (F5) или нажмите «Проверить соединение» в настройках — сработает переинжект.

## Известные ограничения

- `aria-label`-фолбэки рассчитаны на английский/русский UI SoundCloud;
  основные пути — по классам, они от локали не зависят.
- Длительность без медиа-элемента читается из текста таймлайна («3:45»);
  при отсутствии — 0, телефон просто не покажет общую длительность.
