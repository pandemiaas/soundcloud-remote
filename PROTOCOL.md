# SoundCloud Remote Protocol (SCR-1)

- **Версия протокола:** 1 (`proto: 1`)
- **Статус:** стабилен для Этапов 1–3
- **Транспорт:** WebSocket (текстовые фреймы, один JSON-объект на фрейм)
- **Дата:** 2026-09-26

Протокол связывает три участника. Реализация каждой стороны обязана следовать
только этому документу — встречные поля игнорируются, чтобы версии можно было
обновлять независимо.

---

## 1. Топология

```
┌──────────────────────┐   ws://<IP_ПК>:8765/ws   ┌──────────────────────────┐
│  Телефон (Android)   │ ◄──── роль "remote" ────►│  ПК-мост (Tauri/Rust)    │
│  WebSocket-клиент    │                          │  WebSocket-сервер        │
└──────────────────────┘                          └───────────┬──────────────┘
                                                              │ ws://127.0.0.1:8765/ws
                                                              │ роль "extension"
                                                  ┌───────────▼──────────────┐
                                                  │  Chrome Extension (MV3)  │
                                                  │  во вкладке soundcloud   │
                                                  └──────────────────────────┘
```

- Мост — единственный **сервер**. Телефон и расширение — клиенты.
- Мост мультиплексирует две **роли**; роль объявляется в `hello`.
- Телефон никогда не обращается к браузеру напрямую.

## 2. Транспорт и аутентификация

| Параметр | Значение |
|---|---|
| Порт по умолчанию | `8765` |
| Путь | `/ws` (настраивается) |
| Формат | UTF-8 JSON, одно сообщение = один текстовый фрейм |
| Ограничение размера | 64 КиБ на сообщение |

**Аутентификация:**

- Роль `remote` (телефон) обязана прислать `token` в `hello`. Токен — строка
  из 6+ цифр/символов, генерируется мостом и показывается в QR-коде.
  Неверный токен → `error {code:"auth"}` и закрытие соединения.
- Роль `extension` подключается только с `127.0.0.1` / `::1` (loopback) и
  **принимается без токена** — loopback доверенный. Это осознанное упрощение,
  чтобы расширение не требовало настройки.

**QR-код подключения (для телефона):**

```
scremote://connect?host=192.168.1.5&port=8765&token=482153
```

Трафик не шифруется (TLS на LAN не применяем в v1); секрет соединения — токен.
Токен меняется кнопкой «Перевыпустить» в мосту.

## 3. Конверт и общие правила

- Каждое сообщение имеет обязательное строковое поле `t` (type).
- Числа — без кавычек. Время — целые **миллисекунды** (`*_ms`).
- Неизвестные поля получатель игнорирует; неизвестный `t` отвечает
  `error {code:"bad_message"}`.
- Версия: клиент шлёт `proto: 1` в `hello`. Несовпадение мажорной версии →
  `error {code:"unsupported_proto"}` и закрытие соединения.
- Все строки — в UTF-8, имена полей — `snake_case`.

## 4. Роли и возможности (caps)

`caps` — массив строк, честно описывающий, что сторона умеет **прямо сейчас**.
Телефон показывает только те контролы, которые покрыты объединением
`caps` моста и `caps` расширения, и прячет остальные.

| Cap | Кто объявляет | Значение |
|---|---|---|
| `metadata` | extension | название/исполнитель/обложка |
| `position` | extension | позиция воспроизведения (tick) |
| `play`, `toggle` | extension | play/pause/toggle |
| `next` | extension | next + prev (объявляются парой) |
| `seek` | extension | перемотка |
| `player_volume` | extension | громкость плеера SoundCloud |
| `like` | extension | лайк |
| `repeat` | extension | повтор (off/all, возможно one) |
| `shuffle` | extension | перемешивание (может требовать открытия очереди) |
| `system_volume` | bridge | системная громкость Windows |

Расширение может прислать обновлённый список в любой момент сообщением
`caps` (например, когда вкладка SoundCloud открылась/закрылась).

## 5. Сообщения: телефон → мост (роль `remote`)

| `t` | Поля | Описание |
|---|---|---|
| `hello` | `role:"remote"`, `proto`, `token`, `name?` | рукопожатие; ответ `welcome` или `error` |
| `ping` | — | keepalive; ответ `pong` |
| `sync` | — | запросить полный `state` |
| `play` / `pause` / `toggle` | `id?` | управление воспроизведением |
| `next` / `prev` | `id?` | переключение трека |
| `seek` | `id?`, `ms` | перейти на позицию (обрезается в `[0, duration]`) |
| `volume` | `id?`, `target:"player"\|"system"`, `value:0..100` | громкость |
| `like` | `id?`, `on: true\|false\|null` | `null` = переключить |
| `repeat` | `id?`, `mode:"off"\|"all"\|"one"` | режим повтора |
| `shuffle` | `id?`, `on: true\|false` | перемешивание |

Поле `id` (число, произвольное) — если телефон ждёт подтверждение, мост
вернёт `ack`/`error` с тем же `id`. Без `id` команда fire-and-forget:
результат всё равно придёт обновлённым `state`/`meta`.

Примеры:

```json
{ "t": "hello", "role": "remote", "proto": 1, "token": "482153", "name": "Pixel 8" }
{ "t": "seek", "id": 17, "ms": 95000 }
{ "t": "volume", "id": 18, "target": "system", "value": 40 }
{ "t": "repeat", "mode": "all" }
```

## 6. Сообщения: расширение → мост (роль `extension`)

| `t` | Поля | Описание |
|---|---|---|
| `hello` | `role:"extension"`, `proto`, `ext:"chrome"`, `version`, `caps` | рукопожатие; ответ `welcome` |
| `ping` | — | keepalive; ответ `pong` |
| `state` | полный снапшот (см. §9) | шлётся при изменениях и по `sync` от моста |
| `tick` | `position_ms`, `playing`, `volume_player` | каждые ~1000 мс |
| `caps` | `caps: []` | обновление списка возможностей |
| `ack` | `id`, плюс поля результата | успех выполнения команды с `id` |
| `error` | `id?`, `code`, `message?` | отказ/ошибка (см. §10) |
| `ext` | `connected: true\|false` | вкладка SoundCloud появилась/исчезла |

## 7. Сообщения: мост → телефон (роль `remote`)

| `t` | Поля | Описание |
|---|---|---|
| `welcome` | `proto`, `device`, `bridge_version`, `caps` | после успешного `hello` |
| `pong` | — | ответ на `ping` |
| `state` | полный снапшот (см. §9) | после `hello`, по `sync`, при расхождениях |
| `tick` | `position_ms`, `playing` | каждые ~1000 мс; телефон дорисовывает прогресс между тиками |
| `meta` | любые из `liked`, `repeat`, `shuffle`, `volume_player`, `volume_system` | точечное обновление без полного state |
| `track` | `track: {...}` | смена трека (удобство-дубликат) |
| `ext` | `connected: bool`, `caps?` | вкладка SoundCloud подключена/отвалилась |
| `ack` | `id` + поля результата | подтверждение команды |
| `error` | `id?`, `code`, `message?` | ошибка |

## 8. Сообщения: мост → расширение (роль `extension`)

Мост ретранслирует команды телефона как есть (`play`, `pause`, `toggle`,
`next`, `prev`, `seek`, `volume` c `target:"player"`, `like`, `repeat`,
`shuffle`) с сохранением `id`. Дополнительно:

| `t` | Описание |
|---|---|
| `welcome` | `{ proto, bridge_version }` |
| `pong` | ответ на ping расширения |
| `sync` | запросить свежий полный `state` |
| `ping` | пинг со стороны моста (расширение отвечает `pong`) |

Команду `volume` с `target:"system"` расширение **не получает** — системную
громкость мост меняет сам средствами ОС.

## 9. Объект `state`

Расширение шлёт подмножество; мост добавляет свои поля и пересылает телефону
полный снапшот:

```json
{
  "t": "state",
  "playing": true,
  "position_ms": 61234,
  "duration_ms": 213000,
  "volume_player": 80,
  "volume_system": 45,
  "repeat": "off",
  "shuffle": false,
  "ext_connected": true,
  "caps": ["metadata", "position", "play", "next", "seek", "player_volume", "like", "repeat", "shuffle"],
  "track": {
    "title": "Название трека",
    "artist": "Исполнитель",
    "artwork": "https://i1.sndcdn.com/artworks-xxx-t500x500.jpg",
    "liked": false,
    "url": "https://soundcloud.com/artist/track"
  }
}
```

Правила:

- `track: null`, если во вкладке ничего не открыто/не играет.
- `repeat` может быть `null`, а `shuffle` — `null`, если состояние кнопки
  сейчас нечитаемо (см. README расширения): телефон держит последнее
  известное значение и помечает контрол нейтральным.
- `liked` может быть `null` (кнопки нет).
- Смена трека всегда сопровождается полным `state`; поле `position_ms`
  в момент смены = 0.
- Телефон после `seek` сразу выставляет позицию локально и корректирует её
  по следующему `tick`.

## 10. Коды ошибок

| Код | Значение |
|---|---|
| `auth` | неверный/отсутствующий токен |
| `unsupported_proto` | несовпадение версии протокола |
| `bad_message` | неизвестный `t` / невалидный JSON / битые поля |
| `unavailable` | действие невозможно сейчас (нет вкладки SoundCloud, кнопки в DOM, медиа-элемента) |
| `unsupported` | команда не поддерживается этой стороной |
| `internal` | прочие ошибки |

Формат: `{ "t": "error", "id": 17, "code": "unavailable", "message": "human text" }`.

## 11. Тайминги и реконнект

| Параметр | Значение |
|---|---|
| `tick` | каждые 1000 мс, только из расширения |
| `ping` | каждые 20 с с обеих сторон клиентских соединений |
| Реконнект (телефон и расширение) | экспоненциально: 1 → 2 → 4 → … → 30 с, сброс при успехе |
| После реконнекта | обязательные `hello` и `sync`/`state` |
| Таймаут ответа на команду с `id` | 5 с, затем `error {code:"internal"}` |
